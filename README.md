# INDIAN BUS DRIVER SIMULATOR

**A game by ANI STUDIO**

A Roblox driving-simulator project. The current starter feature is a responsive main menu with **PLAY**, **CREDITS**, and **EXIT**.

## Current files

- `src/client/MainMenu.client.lua` — builds the menu in Roblox at runtime.
- `default.project.json` — Rojo project mapping for the client script.

## Important

This repository contains Roblox/Luau project source, not a native Android APK. Roblox games can be played on supported Android devices through the Roblox app.

The PLAY button currently displays a development notice. It does not yet load the bus stand or driving gameplay. Roblox scripts also cannot close the Roblox app; EXIT explains how to leave using Roblox's own menu.

## Open in Roblox Studio

The easiest way to sync this project from GitHub into Roblox Studio is with [Rojo](https://rojo.space/). Install Rojo and its Roblox Studio plugin, download/clone this repository, then run:

```sh
rojo serve
```

Connect the Rojo Studio plugin to the local server and press Play to test. The menu LocalScript should appear under **StarterPlayer > StarterPlayerScripts**.
