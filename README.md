# INDIAN BUS DRIVER SIMULATOR

**A game by ANI STUDIO**  
Mobile-first Roblox bus driving project with a procedurally generated 3D Agartala-inspired map.

## Download the project

- **[Download the latest project ZIP](https://github.com/anirudhadebbarma031214-commits/INDIAN-BUS-DRIVER-SIMULATOR/archive/refs/heads/main.zip)**
- [Open the GitHub project](https://github.com/anirudhadebbarma031214-commits/INDIAN-BUS-DRIVER-SIMULATOR)
- [View the 3D Agartala map script](https://github.com/anirudhadebbarma031214-commits/INDIAN-BUS-DRIVER-SIMULATOR/blob/main/src/server/AgartalaMap.server.lua)
- [View mobile driving controls](https://github.com/anirudhadebbarma031214-commits/INDIAN-BUS-DRIVER-SIMULATOR/blob/main/src/client/BusControls.client.lua)

> The ZIP contains the game's source files. It is **not** an Android APK or a ready-to-play Roblox game link. Roblox gameplay must be opened in Roblox Studio and published to Roblox before it can be tested in the Roblox mobile app.

## What's included

- Runtime-generated 3D Agartala-inspired city layout: roads, market/shop blocks, trees, Badarghat-style homes, Ujjayanta Palace-inspired landmark, railway station, airport and Udaipur highway destination.
- Bus fleet and server-side driving prototype.
- Touchscreen driving buttons for mobile, plus keyboard controls for Studio testing.
- Main menu, route selector, minimap, speedometer and vehicle status UI.

The map is an original, simplified layout inspired by Agartala, not a surveyed 1:1 recreation of the city. Generated scenery and driving need testing in Roblox Studio; no successful test is claimed yet.

## Test it in Roblox Studio

1. Download the ZIP above and extract it to a folder on your PC.
2. Install [Roblox Studio](https://create.roblox.com/) and [Rojo](https://rojo.space/) (including the Rojo Studio plugin).
3. Open Command Prompt in the extracted project folder — the folder containing `default.project.json`.
4. Run `rojo serve`.
5. In Roblox Studio, open a Baseplate place, open the Rojo plugin, connect to the local Rojo server, and sync the project.
6. Press **Play** in Studio. Check that the city appears, approach a bus, and try the **Drive Bus** prompt.
7. To test on a phone, publish the place from Studio to your Roblox account, set the experience's access/permissions as desired, then open that Roblox experience in the Roblox mobile app. Touch controls are intended to appear while driving.

## Important
